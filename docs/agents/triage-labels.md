# Labels de triage

Les compétences parlent en termes de cinq rôles de triage canoniques. Ce fichier fait
correspondre ces rôles aux libellés réels utilisés sur le tracker de ce dépôt.

| Label côté mattpocock/skills | Label sur ce dépôt | Sens                                          |
| ----------------------------- | ------------------- | ---------------------------------------------- |
| `needs-triage`                 | `needs-triage`       | Le mainteneur doit évaluer cette issue         |
| `needs-info`                   | `needs-info`         | En attente d'informations du rapporteur        |
| `ready-for-agent`              | `ready-for-agent`    | Entièrement spécifiée, prête pour un agent seul |
| `ready-for-human`              | `ready-for-human`    | Nécessite une implémentation humaine           |
| `wontfix`                      | `wontfix`             | Ne sera pas traitée                            |

Les cinq labels existent déjà sur `Not-Nailec/Press-Start-Partage` (créés le 15/09/2026 lors de la
configuration de ce pipeline).

Quand une compétence mentionne un rôle (« applique le label ready-for-agent »), utiliser le
libellé correspondant de cette table.
