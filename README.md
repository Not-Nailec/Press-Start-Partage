## ✨ Ce que fait Press Start

| Module | Ce qu'il apporte |
|---|---|
| 🔎 **Détection** | L'état complet de la machine, composant par composant : CPU, carte mère, GPU, RAM, disques, écrans, réseau — avec un bilan de santé par composant. |
| 📊 **Monitoring** | Toutes les mesures en direct, comme un tableau de bord : températures, charges, fréquences, ventilateurs, réseau et consommation (watts). |
| 🌀 **Refroidissement** | Le pilotage des ventilateurs, simple ou avancé : profils Silencieux / Équilibré / Performance, mode adaptatif, arrêt 0 RPM au repos, et réglage par ventilateur avec configuration guidée. |
| ⬇️ **Installation** | Mettre la machine à jour et bien la régler : pilotes manquants, plan d'alimentation, XMP, activation Windows, et logiciels utiles selon le matériel détecté. |
| 🧪 **Outils & tests** | Vérifier et éprouver : tests de charge, SMART, auto-test NVMe, bench disque, intégrité mémoire — puis un rapport de validation partageable. |
| 🔐 **Compte & licence** | Un accès sécurisé, géré à distance : connexion en ligne, licence et modules activés à distance, profil personnalisable. |

## 🚀 Installer & lancer

1. Ouvrez l'onglet **[Releases](../../releases)** → dernière version.
2. Téléchargez **`PressStart-<version>.zip`** sous **Assets**.
3. **Avant d'extraire** : clic droit sur le `.zip` → **Propriétés** → cochez **« Débloquer »** → **OK**.
4. **Extrayez** le dossier, puis lancez **`PressStart.exe`**.

> ⚠️ Windows (SmartScreen) ou l'antivirus peut afficher un avertissement, car le logiciel n'est pas encore signé : cliquez sur **« Informations complémentaires » → « Exécuter quand même »**.

---

## 🔄 Mises à jour automatiques

Press Start se **met à jour tout seul**. Dès qu'une nouvelle version est publiée, elle est téléchargée et installée en arrière-plan, sans manipulation ni perte de vos réglages. Un écran **« Nouveautés »** résume l'essentiel à chaque version.
